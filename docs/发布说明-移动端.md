配套 **DSH 远程控制** 电脑端插件（`v1.0.2` 及以后）的 Android 客户端。

这个 APK **只能连接电脑**：它没有本地 DSH 引擎，只负责把请求打包成加密的 7z 包、
写进你自己的 B2 私有桶。所有会话、所有数据都留在那台电脑上。

## 安装

1. 下载下面的 `dsh-remote-control-android-1.0.0.apk`
2. Android 8.0+（minSdk 26），系统里需要允许「安装未知来源应用」
3. 打开后填**和电脑端设置页完全一样**的 5 项：

   | 项 | 说明 |
   |---|---|
   | Application Key ID | B2 控制台里那把 key 的 `keyID` |
   | Application Key | 同一把 key 的 `applicationKey` |
   | Bucket 名称 | 桶名。用**全能力 key** 必填（授权不返回 bucketId）；限定单桶的 key 可留空 |
   | 云端文件名 | 决定「连哪台电脑」，和电脑端那台保持一致 |
   | 加密密码 | 每个 7z 包的密码，不参与通道派生，填错会报「解不开」 |

4. 点 **保存并连接**，状态灯变绿就是在收发了。

## 校验

- 包名 `dshremote.app`，版本 `1.0.0`（versionCode 1），76.7KB
- 签名证书 SHA-256：`669498d05e62bd03dbac460d82c3b8ba62d22dfc4a396abf607e24988f5928ef`
- 后续版本沿用同一把 keystore，可以直接覆盖安装；若手机上是别处来的包，先卸载再装

## 电脑端

在 DSH 里打开 **设置 → 插件 → 添加**，粘贴：

```
https://github.com/10jinzhi/dsh-remote-control
```

想钉版本就加 `#v1.0.2`（`v1.0.0` 会启动崩溃、`v1.0.1` 设置面板空白，别用）。
